# O Desafio de Platão — A Jornada dos Sólidos Platônicos

Jogo educacional HTML5 para o Ensino Médio.

## Conteúdo
- 40 questões
- 3 fases
- Mapa visual da aventura
- Cinco sólidos platônicos
- Relação de Euler
- Áreas, volumes e dualidade
- Pontuação, vidas, feedback e medalhas

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie TODOS os arquivos deste pacote para a raiz do repositório.
3. Abra Settings > Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Clique em Save.
7. Aguarde o GitHub gerar o endereço público do jogo.

O arquivo inicial deve permanecer com o nome `index.html`.
